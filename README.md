# NETGAIN Doctoral Focal Award

Source for the NETGAIN website, published at [netgain-dfa.org](https://netgain-dfa.org) via GitHub Pages.

NETGAIN is a UKRI Doctoral Focal Award on the science and practice of nature markets, delivered by the Universities of St Andrews, Glasgow, Aberdeen and Durham with industry and policy partners. It trains doctoral researchers to work across disciplinary and sectoral boundaries on net gain and the design of nature markets.

## Contents

- `src/`: page content and templates
- `public/`: images, logos and downloads

## Updating the site

Edit files on the `main` branch and GitHub Pages rebuilds automatically within a few minutes. Build and contribution instructions will be added once the site scaffold is in place.
